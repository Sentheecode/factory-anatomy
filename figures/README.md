# Interactive HTML demos

Open each `.html` file in a **desktop browser** for live animation. These are large, self-contained standalone demos (not meant to be embedded in iframes without loading the full file).

| File | Scene |
| --- | --- |
| `stamping-jier-line-light.html` | Stamping line |
| `bodyshop-biw-desktop-light.html` | Body shop (BIW) |
| `paintshop-3f-desktop-light.html` | Paint shop (3 floors) |
| `assembly-nev-desktop-light.html` | NEV final assembly |
| `battery-pack-line-light.html` | Battery pack line |
| `edu-drive-desktop-light.html` | Electric Drive Shop (EDS) — shop overview |
| `edu-drive-unit-light.html` | Electric Drive Shop (EDS) — 3-in-1 product explode |
